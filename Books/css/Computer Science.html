Computer Science C++ How to Program by Harvey M. Deitel & Paul Deitel – Useful for programming fundamentals and object-oriented concepts in C++ (covers part of the programming portion of the syllabus). Operating System Concepts by Abraham Silberschatz, Peter Galvin, and Greg Gagne – A standard textbook covering operating system principles, which aligns with the OS portion of the CSS Computer Science syllabus.
